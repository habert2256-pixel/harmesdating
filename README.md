# Harmes Dating

A modern, mobile-first dating website starter built with plain HTML, CSS, and JavaScript.

**Live demo ready** — open `index.html` in any browser. No build step required.

## Features

- Beautiful landing page
- Sign up / Log in (stored in localStorage)
- Swipe-style Discover cards (drag or buttons)
- Like / Pass / Super Like
- Match modal with animation
- Matches grid
- Conversations list
- Profile view + simple bio edit
- Fully responsive
- Dark romantic theme

## How to run

### Option 1 — Open locally
Just open `index.html` in Chrome, Firefox, Safari, or Edge.

### Option 2 — GitHub Pages
1. Create a new repo named `harmesdating`
2. Upload these files (or push via git)
3. Go to **Settings → Pages**
4. Source: Deploy from branch `main` / root
5. Your site will be live at `https://YOUR_USERNAME.github.io/harmesdating`

### Option 3 — Any static host
Works on Netlify, Vercel, Cloudflare Pages, etc. Just drag the folder.
